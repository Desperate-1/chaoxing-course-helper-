# 学习通网课助手（Chaoxing Course Helper）

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Version](https://img.shields.io/badge/version-1.43-blue.svg)](CHANGELOG.md)
[![ScriptCat](https://img.shields.io/badge/ScriptCat-%E5%8F%AF%E7%94%A8-2f9e44)](https://scriptcat.org)

一个跑在 **ScriptCat（脚本猫）/ Tampermonkey（油猴）** 上的学习通（超星）网课自动化脚本。

自动播放视频、断点续看、切后台不掉线；章节测试自动答题（本地题库 + DeepSeek AI 双引擎），答完自动穿透「确认提交」弹窗交卷。

> ⚠️ 本项目仅用于**前端自动化技术的学习与交流**。使用本脚本可能违反学校规定与平台用户协议，请自行评估风险，详见文末[免责声明](#免责声明)。

## 功能特性

### 📺 视频自动播放

- **自动播放、自动切下一节**，任务列表实时显示进度
- **倍速可调**（默认 1 倍速，界面内随时改，建议不超过 2 倍，太快平台可能判定异常）
- **断点续看**：自动读取平台已记录的观看进度，从上次位置继续，不用从 0 秒重刷
- **自动跳过已完成任务**，也可以开「复习模式」强制重刷

### 🛡️ 后台防休眠（v1.43）

以前把浏览器最小化 / 切到别的标签页，浏览器为了省电会把页面「冻住」，视频时间不走、卡住不跳下一集。本版本的处理：

- 劫持 `document.hidden` / `visibilityState`，让页面始终认为自己是可见的
- 用 **Web Worker** 跑定时器，绕开后台标签页的 1 分钟节流
- 用系统真实时间计时，电脑卡顿后自动补齐进度

结果：最小化挂着也能按 60 秒一次的节奏正常汇报学习进度。

### 🧠 章节测试自动答题（题库 + AI 双引擎）

1. 先从**题库**查答案（命中即用，速度快）
2. 题库未收录的题，自动发给 **DeepSeek AI** 现场作答
3. 识别题型（单选 / 多选 / 判断），自动点选对应选项
4. 达到设定正确率才自动提交，否则自动保存答案，等你手动确认

> 正确率门槛的算术公式修好了原版「错一题就算 0% 拒绝交卷」的 bug。

### 📝 自动交卷

- 死死盯住「确认提交」弹窗，弹出来立刻点确认并调用底层交卷指令
- 交卷后等页面显示分数和答案，再跳下一章，不会出现「交到一半被脚本掐断」

### 📋 其他

- 运行日志面板（实时看脚本在干嘛）
- 后台任务页（`unrivalxxtbackground/`），关掉课程页也能继续挂
- 可选自动登录（默认关闭，不建议用，见 [FAQ](#常见问题)）

## 安装

### 第一步：装一个脚本管理器

脚本管理器就是「给浏览器装外挂」的插件。二选一：

| 管理器 | 适用浏览器 | 下载 |
| --- | --- | --- |
| **ScriptCat 脚本猫** | Chrome / Edge / 其他 Chromium | [scriptcat.org](https://scriptcat.org) →「下载安装」 |
| **Tampermonkey 油猴** | Chrome / Edge / Firefox | [tampermonkey.net](https://www.tampermonkey.net/) |

> 本脚本是在 **ScriptCat** 上开发的，推荐用脚本猫。油猴基本也能跑，但不保证。

### 第二步：安装脚本

**方式 A：一键安装（推荐）**

装好脚本管理器后，直接打开下面这个地址，脚本猫/油猴会弹出安装页，点「安装」即可：

```
https://raw.githubusercontent.com/YOUR_NAME/chaoxing-course-helper/main/chaoxing-course-helper.user.js
```

> 把上面地址里的 `YOUR_NAME` 换成你的 GitHub 用户名。如果打不开，说明你所在网络访问 `raw.githubusercontent.com` 困难，用方式 B。

**方式 B：手动导入**

1. 下载仓库里的 [`chaoxing-course-helper.user.js`](chaoxing-course-helper.user.js)
2. 打开脚本猫 →「工具」→「导入脚本」，选中这个 `.user.js` 文件
3. 或者把文件内容复制到脚本猫「新建脚本」里，保存

### 第三步：验证

打开学习通的课程页面（`*.chaoxing.com` 的课程学习页），如果页面被替换成带「任务配置 / 任务列表 / 运行日志」的面板，说明装好了。

## 快速上手

1. **打开课程学习页**（有视频列表的那个页面），脚本会自动接管
2. **设置视频倍速**：在「视频倍速」框里填数字（比如 `2`），点「保存」
3. **（可选）填 DeepSeek API Key**：只打算用题库答题的话可以留空
   - 去 [DeepSeek 开放平台](https://platform.deepseek.com/) 注册 → 创建 API Key（`sk-` 开头）
   - 粘到「DeepSeek Key」输入框，点「保存」
   - Key 只存在你本机浏览器里，脚本不会上传
4. **打开「自动答题」「自动提交」开关**（按钮变绿就是开了）
5. 挂机就行。想切后台就点「后台挂机」，在后台任务页看进度

> 第一次用建议把倍速设成 `1`，完整跑完一小节确认没问题，再调高。

## 配置项说明

脚本的设置都存在浏览器本地（`GM_setValue`），换浏览器/换脚本管理器会丢。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 视频倍速 | `1` | 视频播放倍速。填 `0` 会直接跳过视频任务（不推荐） |
| 复习模式 | 关 | 开启后，已完成的视频也会重新刷一遍 |
| 自动答题 | 开 | 自动做章节测试 |
| 自动提交 | 开 | 正确率达到门槛自动交卷 |
| 自动保存 | 关 | 正确率不达标时自动保存答案 |
| DeepSeek API Key | 空 | 留空则只用题库答题 |

**正确率门槛**：脚本内写死了 `accuracy = 0`（即只要答完就允许提交）。想要更稳，可以打开脚本把 `accuracy = 0` 改成 `accuracy = 80`，这样正确率低于 80% 就只保存不提交。

## 常见问题

**Q：装好了但页面没变化？**

1. 确认脚本管理器里这个脚本是「启用」状态
2. 刷新页面（`Ctrl + F5` 强制刷新）
3. 确认当前网址是课程学习页（`knowledge/cards`），不是首页
4. 看脚本管理器的「日志」里有没有报错

**Q：提示「您的浏览器内核过老」？**

脚本要求 Chrome 内核 ≥ 86。升级浏览器，或换 Edge / Chrome。

**Q：DeepSeek 报错 `400 / 404 / 401`？**

- `401`：Key 填错了，或者余额不足
- `404`：模型名不对。脚本里默认是 `deepseek-flash`，官方模型名一般是 `deepseek-chat`，打开脚本把 `dsModel` 改掉
- 报跨域：确认脚本头部有 `@connect api.deepseek.com`

**Q：一直卡在某一章不动？**

- 大概率是这一章视频被平台标记为「已完成」，脚本按规则跳过。打开「复习模式」再试
- 或者这一章是「闯关模式」，需要先完成前面的章节

**Q：题库没答案 / 答题率很低？**

题库接口是第三方服务（`cx.icodef.com`），可能限流、收费或失效。失效时脚本会自动降级到 DeepSeek AI 答题，前提是你填了 Key。

**Q：会不会被平台检测到 / 封号？**

**会。** 平台有切屏检测、时长异常检测、答题速度检测。本脚本做了部分规避（屏蔽切屏、随机答题间隔 2.5~4.5 秒），但**不能保证安全**。学校也可能通过后台数据判定作弊。**风险自负。**

**Q：为什么不用自动登录？**

自动登录需要把你的手机号和密码明文存在脚本设置里，一旦脚本被改、或者你换了设备，密码就有泄露风险。**强烈建议手动登录。**

## 技术细节

感兴趣可以看看实现思路：

| 问题 | 做法 |
| --- | --- |
| 后台标签页定时器被节流到 1 次/分钟 | 用 `Blob` + `Worker` 起独立线程跑 `setInterval`，Worker 不受页面节流影响 |
| 切后台后 `visibilitychange` 被平台监听 | `Object.defineProperty` 重写 `document.hidden` / `visibilityState`，并在捕获阶段 `stopImmediatePropagation` |
| 计时不准（电脑卡顿导致少算） | 用 `Date.now()` 真实时间差计算进度，而非累加计数 |
| 交卷弹窗点不到 | `MutationObserver` 监听弹窗 DOM，出现即模拟点击 + 直接调用 `submitWork` 底层方法 |
| 断点续看 | 从章节任务接口返回的 `headOffset` / `playTime` 读取已看秒数，作为起始进度 |

## 隐私说明

这个脚本会联网，把数据发到哪里，说清楚：

| 数据 | 发往 | 什么时候 |
| --- | --- | --- |
| 课程任务信息、学习进度 | 学习通服务器（`*.chaoxing.com`） | 正常刷课，和你手动看视频一样 |
| 题目文本 | 第三方题库 `cx.icodef.com` | 每次答题前查题库 |
| 题目文本 | `api.deepseek.com` | 题库没查到，且你填了 Key |
| DeepSeek API Key | **只存在本机** | 不上传、不写日志 |
| 手机号 + 密码 | `passport2-api.chaoxing.com`（学习通官方登录接口） | **仅当你启用「自动登录」时**，且以 GET 参数明文提交，建议保持关闭 |

- 脚本**不收集**任何个人信息、不做遥测、不加载广告
- 脚本里**没有**任何向作者服务器回传数据的代码
- 脚本会读取学习通自己的 `_uid` / `fid` Cookie，用来拼接学习通接口的参数，这些值只发给 `*.chaoxing.com`，不会外传
- 但请注意：题目内容会发给上述第三方，介意的话可以把 `ctUrl` 改成你自己的题库地址，或者把题库请求那段注释掉
